## 5. 版本使用原则

1. `Firmware` 分别保存原比赛冻结ELF和本轮记录版ELF；`build/Debug` 当前为记录版。
2. 本次沿用机械水平、PD、原 IMU 前馈和停车补偿参数，新增项单独试调并记录结果。
3. 修改前资料已备份到 `Documentation/Backups/2026-10-04-before-startup-feedforward.zip`。
4. `build` 属于可再生成目录，不作为最终版本的一部分保存。

## 6. 编译和烧录

手动修改参数后：

```powershell
Set-Location F:\260801_电赛省赛\H_BallBalance_CBoard
. .\Tools\Enter-CBoardEnv.ps1
cmake --preset Debug
cmake --build --preset Debug
.\Tools\Flash-CBoard.ps1
```
