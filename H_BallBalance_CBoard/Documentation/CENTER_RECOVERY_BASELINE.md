# 回中控制真机基准

本文最初记录 2026-08-01 的回中基准。2026-08-23 项目收尾时，当前源码
`Kp=0.25`、`Kd=0.15` 已随任务1～6完成真机验证，最终状态见 `CURRENT_PROGRESS.md`。

## 已接受参数

- 位置比例增益：`Kp = 0.25 deg/mm`
- 速度阻尼增益：`Kd = 0.145 deg/(mm/s)`
- 正常角度偏移限幅：`±3°`
- 中心区间：`[-3 mm, +3 mm]`，包含边界
- 进入中心保持的速度上限：`10 mm/s`
- 进入中心保持的确认条件：连续三张不同的新鲜视觉图
- 退出中心保持：第一张落在 `[-3 mm, +3 mm]` 外的新鲜视觉图

## 已接受行为

球位于中心区间外时，位置控制器继续工作。球进入中心区间后，只有位置条件和低速
条件连续被三张不同的新鲜视觉图确认，机构才回到已配置的机械水平。重复发送的
50 Hz 协议包不能计为新图。视觉新鲜度、置信度、电机、角度、速度、电流和故障
保护保持启用且参数不变。

## 运行时数值

不会自动恢复本文基准。

## 任务 3 复用

任务 3 在三个目标点复用同一控制器和同一回中确认条件。树莓派在 O 点、`+5 cm`
和 `-5 cm` 均要求目标误差不超过 `3 mm`、速度绝对值不超过 `10 mm/s`，并由连续
三张不同的新鲜视觉图确认。任一张新图不满足时，连续计数立即清零。

C 板继续计算 `error = target_x - x`；C 板不生成 `0→+500→-500` 目标序列，也不
判断任务完成。
