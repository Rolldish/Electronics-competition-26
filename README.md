# 2026 电赛工程资料

本仓库用于归档 2026 年电赛相关工程，包括视觉识别、云台控制、机械结构设计及相关程序。

主要提供工程源码与设计文件，供下载、调试和复现使用。

## 1. 工程目录

| 文件 / 目录 | 内容 |
|---|---|
| `26XinKun_GimbalControl.zip` | 云台控制工程 |
| `26XingKun_Vision.7z` | 视觉识别工程 |
| `H_Ball_Control_Vision.zip` | H 题视觉与控制相关工程 |
| `机械设计/` | 机械结构设计文件 |

建议分别下载所需模块，解压后查看对应工程文件。

## 2. 复现准备

### 硬件环境

按需准备以下设备，具体型号需与工程配置保持一致：

- 主控开发板：`大疆c板`
- 视觉处理设备及摄像头：`树莓派5B+usb摄像头`
- 电机、驱动模块及电源：`QD4310`
- 机械结构及连接件：参考 `机械设计/`
- USB 数据线、调试串口及连接线

### 软件环境

根据工程实际使用的开发工具进行配置：

| 模块 | 开发环境 |
|---|---|
| 云台控制 | `Clion+Cubemx+Cmake` |
| 机器视觉 | `Raspberry Pi` |
| 机械设计 | `Solidworks` |

使用工程原有的软件及依赖版本，避免因版本差异导致编译或运行失败。

## 3. 下载工程

**方式一：直接下载**

1. 进入仓库对应分支。
2. 点击 **Code → Download ZIP**。
3. 解压仓库后，找到所需工程文件。
4. 将工程压缩包分别解压到独立目录。

**方式二：Git 克隆**

```bash
git clone -b happyr0okiie https://github.com/Rolldish/Electronics-competition-26.git
cd Electronics-competition-26
```

其中 `.7z` 文件可使用 7-Zip 解压。

## 4. 工程运行

### 4.1 云台控制

对应文件：`26XinKun_GimbalControl.zip`

1. 解压工程。
2. 使用对应 IDE 打开工程文件。
3. 检查主控型号、时钟、引脚与外设配置。
4. 按照实际硬件连接驱动器及执行机构。
5. 编译工程并烧录到主控。
6. 上电后测试云台各轴运动方向和响应。

注意：首次运行建议限制运动范围，检查电机方向和机械限位，避免发生结构碰撞。

### 4.2 视觉识别

对应文件：`26XingKun_Vision.7z`

1. 解压工程。
2. 安装对应开发环境及依赖。
3. 连接摄像头或视觉处理设备。
4. 检查图像采集配置及设备连接。
5. 编译或运行视觉程序。
6. 根据实际环境调整必要参数，确认目标识别与坐标输出正常。

### 4.3 H 题相关工程

对应文件：`H_Ball_Control_Vision.zip`

1. 解压工程并检查文件结构。
2. 配置对应硬件及软件环境。
3. 检查视觉输入、控制输出及通信接口。
4. 分别测试视觉和控制功能。
5. 完成模块连接后进行联合调试。

### 4.4 机械结构

对应目录：`机械设计/`

1. 使用对应 CAD 软件打开设计文件。
2. 核对尺寸、装配关系和零部件。
3. 按照设计文件完成加工或打印。
4. 安装电机、摄像头及其他电子模块。
5. 检查机械限位、运动范围和安装稳定性。

## 5. 系统联调

建议按以下顺序进行：

```text
机械结构装配
      ↓
主控与驱动测试
      ↓
视觉模块单独测试
      ↓
模块通信测试
      ↓
执行机构方向校准
      ↓
视觉与控制联合调试
      ↓
整机运行测试
```

联调前重点确认：

- 各模块电源电压、电流及接地符合硬件要求。
- 通信接口、波特率或其他通信参数一致。
- 视觉坐标与机械运动方向对应正确。
- 控制输出没有超过机械允许范围。
- 视觉目标丢失或通信中断时，系统能够安全停止或进入预定状态。

## 6. 常见问题

**Q：工程无法编译？**

检查开发环境、编译工具、SDK 版本和工程路径，确认依赖文件完整。

**Q：摄像头没有图像？**

检查摄像头连接、设备权限、图像采集配置及供电。

**Q：云台运动方向错误？**

检查电机连接、控制方向定义以及机械安装方向。

**Q：识别正常但云台不动作？**

优先检查模块通信、控制指令解析、驱动供电以及使能状态。

**Q：系统运行不稳定？**

分别检查供电、机械松动、视觉识别稳定性、通信延迟和控制参数。

## 8. 注意事项

本仓库包含竞赛期间的工程归档，部分参数可能与当时使用的硬件直接相关。

复现时应以工程实际配置为准，特别注意硬件型号、引脚连接、相机参数、通信方式及机械结构差异。

首次运行建议先进行模块测试，确认安全后再开展整机联调。
