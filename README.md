# 2026 全国大学生电子设计竞赛 H 题省一等奖作品——华南理工大学

本项目为华南理工大学 2026 年全国大学生电子设计竞赛 H 题省一等奖作品。系统围绕车载球体运动控制任务展开，以移动底盘与龙门架机构为主体，结合视觉识别、嵌入式控制、运动执行和机械结构设计，完成整机方案设计、模块调试与竞赛验证。本仓库汇总了比赛期间使用的底盘程序、视觉模块、C 板控制工程、机械设计文件及可打印结构件，便于后续学习、复现与改进。

# 实现内容

* 完成移动底盘循迹、速度控制与多版本运动控制程序设计。
* 完成视觉识别、坐标信息处理及控制模块间通信。
* 完成 C 板驱动、执行机构控制与整机联合调试。
* 完成龙门架及相关机械结构设计，并提供部分可打印 STL 文件。
* 按模块划分工程，便于独立测试、参数调整和整机复现。

## 装置优势

* **机械结构清晰，整机布置紧凑。** 装置采用移动底盘与龙门架相结合的结构形式，将运动机构、控制板、视觉设备和上部执行机构分区布置。龙门架能够提供稳定的安装基准和较充足的工作空间，同时避免上层机构过度挤占底盘区域，便于布线、检修和后续扩展。
* **控制任务分层，充分发挥不同平台的特点。** 底盘运动、执行机构和视觉识别由不同控制模块承担：实时性要求较高的电机与运动控制交给嵌入式主控处理，计算量更大的图像任务交给 K230 或树莓派等视觉平台处理。各模块通过明确的数据接口协同工作，降低单一控制器的负担，也便于快速定位问题。
* **移动与作业功能相对独立。** 底盘负责路径跟踪和整车运动，上层机构负责球体相关任务及视觉反馈。两部分可以先分别完成单元测试，再开展整机联合调试，减少机械结构、视觉算法和运动控制相互干扰带来的调试难度。
* **具备多源信息闭环控制能力。** 工程中包含灰度传感器、编码器、姿态信息和视觉识别等多种输入，可分别服务于循迹、速度调节、姿态判断和目标信息获取。相比单纯依靠开环定时控制，多源反馈更有利于装置在不同运动阶段保持稳定、可调的响应。
* **模块化程度高，维护和迭代方便。** 底盘程序、C 板控制、视觉模块和机械设计按分支与目录独立归档。某一模块更换硬件或调整算法时，可以尽量减少对其他模块的影响；同时保留多个底盘与控制版本，方便比较方案、回退参数和继续开发。
* **机械零件便于加工与复现。** 仓库提供龙门架相关设计资料及适配 A1 mini 的可打印 STL 文件，部分连接件可通过桌面级 3D 打印快速制作。这样的设计能够缩短结构验证周期，也便于根据器件尺寸对局部零件进行重新设计和替换。
* **面向竞赛现场的联调效率较高。** 项目将硬件驱动、视觉识别、通信和机械结构拆分验证，能够按照“单模块测试—通信测试—执行机构校准—整机运行”的顺序逐步排查问题。面对现场光照、场地和机械装配误差变化时，可针对具体模块调整参数，而不必整体重构系统。

# 运行与复现

仓库包含多个主控、视觉和机械设计方案，涉及 MSPM0G3507、大疆 C 板、K230、树莓派等平台。开发环境包括 CCS + SysConfig、CLion + CubeMX + CMake，以及 SolidWorks 等。复现时请进入对应分支，根据实际硬件连接、工程配置和机械结构分别完成模块测试，再进行整机联调。

# 注意事项

本仓库为竞赛期间的工程资料归档，不同分支对应不同成员负责的模块与迭代版本。部分控制参数、引脚配置、视觉阈值及机械尺寸与比赛现场硬件直接相关，复现时请结合实际设备进行校准，并在确保机械限位、电源和执行机构安全的情况下开展调试。
